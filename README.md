# 成长册

给孩子们记录成长的家庭小站：文字、照片、视频、语音；家人能一起看、评论、回复、留悄悄话；孩子长大后有自己的账号写私密日记，也可以一键导出成可离线翻看的压缩包。

功能一览：时间轴（按孩子 / 双宝日常 / 分类筛选，每条显示拍摄当天的精准年龄）· 分类相册（旅行、奖状荣誉、考试成绩、第一次、生日等）· 那年今日（前后 3 天）· 评论回复与悄悄话 · 语音与声音档案 · 时间胶囊（写给未来的信）· 成长数据曲线（可对照 WHO / 中国国标女孩参考曲线）· 回顾视频（MP4，生日大屏播放）· 生日问答年年对比 · AI 助手（可选）· 离线导出。

## 部署

不用下载源码，建一个文件夹，放入下面的 `docker-compose.yml`，再 `docker compose up -d` 即可（镜像由 GitHub Actions 自动构建，在仓库 Packages 里可见）：

```yaml
services:
  growth-album:
    image: ghcr.io/lu8010252/growth-album:latest
    container_name: growth-album
    restart: unless-stopped
    ports: ["8010:8010"]
    environment: [MAX_UPLOAD_MB=2048, TZ=Asia/Shanghai]
    volumes: ["./data:/app/data"]
```

更新：`docker compose pull && docker compose up -d`。也可以 `git clone` 本仓库后 `docker compose up -d --build` 自己构建。

访问 `http://服务器IP:8010`，第一次打开会让你创建管理员账号。

- 所有数据都在 `./data`（`posts/<id>/post.json` + `files/` 里的原图原视频原音频，另有 `users.json`、`kids.json`、`growth.json`、`qa.json`）。**备份这个文件夹就是备份全部**，也可以直接交给孩子。
- 反代（1Panel/OpenResty/Nginx）请把请求体上限调大并开启 HTTPS，例如 `client_max_body_size 2048m;`，并把 `proxy_request_buffering off;` 打开，大视频上传更稳。
- 环境变量：`MAX_UPLOAD_MB`（单个文件上限，默认 2048）、`PORT`、`DATA_DIR`。

## 角色

| 角色 | 能做什么 |
| --- | --- |
| 管理员 | 发布、编辑/删除所有成长记录，管理孩子、账号、站点名称 |
| 家人（可发布） | 发布记录和自己的日记，评论点赞 |
| 家人（只读） | 查看、评论、点赞 |
| 孩子 | 同「可发布」；日记默认**私密**，管理员也看不到，除非她自己选择「家人都能看」 |

## 时间轴与精准年龄

- 首页顶部筛选：**全部 / 每个孩子 / 👭 双宝日常**（两个及以上孩子同框的记录）。孩子的名字在「我的 → 孩子」里改，想叫「姐姐」「妹妹」就直接填。
- 每条记录按日期倒序，并显示当天的精准年龄，如「姐姐 9岁2个月15天」（需在孩子资料里填生日）。

## 分类与那年今天

- 发布「成长记录」时可选分类：日常、旅行、奖状荣誉、考试成绩、第一次、生日、学校、兴趣特长、节日；老记录默认算「日常」，编辑时可改。
- 首页顶部可按分类筛选（和孩子筛选叠加）；「珍藏 → 分类相册」按类别展示封面和条数，点进去就是该分类的时间线。
- 首页顶部的大方框（问候 + 孩子年龄）一直显示，切换孩子/分类时位置不变。大方框下面是「📅 那年今日」卡片：自动找出往年同一天**及前后 3 天**的记录，按「N 年前的今天（日期）」分组，没有回忆时不显示。

## 评论、回复与悄悄话

- 每条记录下面是评论区：任何登录的家人都能评论，点「回复」形成对话。
- **署名**：评论框下「署名 / 悄悄话」里可以填署名（比如外公外婆共用一个账号时写上「外公」），会记在这台设备上。想让谁用自己的名字，就在「我的 → 家人账号」给 TA 建一个账号（角色选「家人（只读）」也能评论）。
- **悄悄话**（评论者自己永远看得到）：
  - 🔒 仅管理员：爸爸妈妈之间的手记；
  - 🔒 只给某一个人：指定的家人才看得到；
  - 🕰 留给孩子：对应孩子的账号满 18 岁后才会看到（要先填孩子生日）。
- 回复一条悄悄话，回复也是悄悄话（只有被回复的人和你能看到）。悄悄话**不会**发给 AI，导出时也只带导出者自己能看的评论。

## 语音与声音档案

- 发布页可以直接点 **🎙 录音**，或选择手机里的录音文件（mp3 / m4a / aac / wav / ogg / amr 等）。非通用格式会在后台转成 m4a，所有手机都能播。**浏览器录音需要 HTTPS 访问**（用 1Panel 反代配好证书即可）。
- 「珍藏 → 声音档案」把所有语音按日期汇总，可按孩子筛选，记录 3 岁的奶音正合适。

## 时间胶囊（写给未来的信）

- 「珍藏 → 时间胶囊 → 写一封信」，选收信的孩子，设定**开启日期**或**孩子满几岁那天**；可附照片 / 视频 / 语音。
- 封存后**连作者也看不到内容**，到期前评论、编辑都不可用（只能删除重写）；到期自动开启，之后出现在「已经开启」里。
- 开启后谁能看：「只给收信的孩子（和作者）」或「家人都能看」。

## 成长数据

- 「珍藏 → 成长数据」：记录身高、体重、鞋码，折线图按年龄（没填生日则按日期）画，可看单个孩子，也可以两个孩子叠在一起对比同龄时的样子。下方是记录表，可修改 / 删除。

## 生日问答

- 「珍藏 → 生日问答」：每个孩子每个年龄一份（比如「9岁」），默认 8 个问题，管理员可以改问题。页面按问题把历年回答放在一起，长大后一眼对比。同一年龄再次保存会覆盖旧回答。

## 照片与视频

- 照片保留原图，另生成缩略图和 1800px 的浏览图（手机流量友好）。
- 视频保留原片，同时后台转成 720p H.264 的手机兼容版（处理期间先播放原片）。
- 目前 HEIC 照片可以上传保存，但部分浏览器无法直接显示（会没有缩略图），建议手机相机设置为「兼容性最好」。

## 导出

「我的」页 →「导出」：生成 zip，内含原始照片、视频、语音、每条记录的 Markdown 文字，以及一个 `index.html`，双击就能离线按时间线翻看（含成长数据表、生日问答、已开启的时间胶囊），不依赖本站。

## AI 助手（可选）

「我的」页 → AI 助手 → 设置，填 OpenAI 兼容的接口地址（含 `/v1`）、密钥、模型名即可启用，API 中转站、Hermes Agent 的 API Server（默认 `http://主机:8642/v1`，模型名 `hermes-agent`）都行。写文字用普通模型的中转站更快更省。

- **AI 帮我写**：发布页写几句话，点按钮润色成一段成长日记，可换风格（温暖/幽默/简洁），可一键还原。孩子账号看到的是「AI 帮我看看」：只改错字病句，保留她自己的口吻，并给一句鼓励。
- **成长回顾**：首页点「✨ 成长回顾」，选孩子和月份/年份，生成一篇回顾，可修改后保存为一条记录（带「AI 整理」标记）。
- **隐私**：回顾只使用「成长记录」，**任何日记都不会发给 AI**；「帮我写」只发送你点击按钮时输入框里的文字。密钥保存在 `data/ai.json`（权限 600），不会出现在导出包里，但备份整个 data 目录时会一并带上，注意保管。
- 如果 Hermes 跑在宿主机上，容器里用 `http://host.docker.internal:8642/v1`，并需让 Hermes 监听 `0.0.0.0`（默认只听 127.0.0.1，容器连不上）。

### 自动读取文件时间 · 识别是谁

- **发布时日期自动取文件自带的时间**（新发布时；多个文件取最早的一天；你手动改过日期就不再覆盖）。优先级：照片拍摄时间（EXIF，含 iPhone 的 HEIC）> 视频 / m4a 的录制时间 > 文件名里的日期（`IMG_20240501_…`、微信 `mmexport<毫秒时间戳>` 等）> 文件修改时间。全部在浏览器里读取，不需要 AI。注意：从相册「导入」的文件，修改时间常常是导入那天，页面会标明来源，请核对。
- **识别是谁**：先在「我的」→ 孩子 →「📷 参考照」给每个孩子传 2~5 张清楚的正脸照，之后发布页选好照片点「🧑 识别是谁」，会自动勾选认出的孩子（只增不减，可手动改）。最多抽 6 张照片，缩到 768px 再发送，只在你点按钮时才会发出。
  - 默认走视觉大模型：沿用 AI 助手的接口，模型要能看图；主模型不能看图时，在「AI 助手 → 设置」里填「视觉模型名」。
  - 也可以接自建人脸识别服务（如 CompreFace、DeepFace 包一层）：在「AI 助手 → 设置」填「自建人脸识别接口地址」，填了就不再用大模型。服务器会 `POST` JSON（可带 `Authorization: Bearer <密钥>`）：
    `{"date":"2024-05-01","candidates":[{"id":"k_xx","name":"小明","birthday":"2017-01-01","age":"7岁4个月","refs":["<base64 jpg>",…]}],"images":["<base64 jpg>",…]}`
    期望返回，`results` 与 `images` 顺序一一对应：`{"results":[{"kidIds":["k_xx"]},{"kidIds":[]}]}`
  - **不想折腾 AI 接口？用现成的自建服务**：仓库里的 `face-service/` 就是按上面约定写好的本地人脸识别（InsightFace，纯 CPU，约 1GB 内存，照片不出你的服务器）。推送后 GitHub Actions 会构建镜像 `ghcr.io/lu8010252/growth-album-face:latest`，用 `face-service/docker-compose.yml` 部署（改掉里面的 `FACE_KEY`），然后在成长册「AI 助手 → 设置」填：接口地址 `http://host.docker.internal:8000/identify`，密钥填同一串 `FACE_KEY`。每个孩子多传几张不同年龄的参考照会更准；认不出就调低 `THRESHOLD`（如 0.32），认错就调高（如 0.45）。孩子的脸随年龄变化大，小宝宝阶段准确率会低一些，过一两年更新参考照即可。
  - 参考照缩成 512px 存在 `data/kidrefs/`，导出包里不包含。

## Android App（APK）

仓库里的 `mobile/` 是一个很薄的 Android 外壳（Capacitor）：首次打开填你家成长册的地址，之后直接进入，录音、选照片都走手机系统的权限。

1. 仓库 **Actions → Build Android APK → Run workflow**（改动 `mobile/` 也会自动触发），等几分钟。
2. 到仓库 **Releases → 成长册 Android 安装包**，下载 `growth-album.apk` 安装（需允许「安装未知来源应用」）。
3. 打开 App，填服务器地址。**录音要用 HTTPS 地址**；纯 `http://IP:端口` 也能用，但没有麦克风权限。换地址：「我的」页 →「切换服务器」。

这是调试签名的安装包，自用足够；App 里的界面就是网站本身，所以网站更新后 App 不用重装。已知限制：App 内的「下载原图 / 导出 zip」不会触发下载，这类操作请用手机浏览器或电脑。

## 回顾视频（MP4）

「我的 → 🎬 回顾视频」可以把成长记录里的照片做成 1920×1080 的 MP4：标题页 → 每张照片配日期、孩子当时的年龄和标题字幕（淡入淡出）→ 片尾。生日聚会时拷到 U 盘、投屏或在大屏上直接播放。

- 可选孩子、起止日期、每张停留秒数；只用「成长记录」里的照片（每条最多 2 张），**不含日记、时间胶囊和视频文件**；超过 120 张会均匀抽样。
- 在服务器上用 ffmpeg 生成（同一时间只做一个），页面显示进度，做好后点下载；临时文件放在容器的 `/tmp`，重启或 6 小时后清理，不占 `./data`。
- 需要中文字体：镜像里已装 `fonts-wqy-microhei`。自己构建/改了镜像的话，用 `MOVIE_FONT` 环境变量指定字体文件路径。
- 视频没有配乐，需要的话在播放器里另放音乐。
- 做好的视频在「我的」页的列表里，可以 **▶ 播放**（在线播放，手机/电脑都行）、**⬇ 下载**、**🗑 删除**；服务器上约 6 小时后自动清理。
- Android App 里的下载由 App 接管（存到手机「下载」文件夹，通知栏提示）——需要重新安装最新的 APK（Actions 打包后在 Releases 的 apk-latest）。微信内置浏览器不支持下载文件，请用「▶ 播放」，或在系统浏览器里打开。

## 成长曲线的参考数据

- **WHO 女孩**：身高 0–19 岁、体重 0–10 岁（官方 LMS 表）。
- **中国国标**：0–7 岁身高体重来自 WS/T 423—2022，7–18 岁身高来自 WS/T 612—2018（体重在 7 岁以上没有国标）。两个标准在 7 岁处会有一点小落差。
- 数据由 `scripts/gen-who.js` 生成到 `public/who.js`，来源见脚本注释。参考带只用于对照，不是诊断，有疑虑请咨询儿科医生。
